01背景

原方案以品线维护多个规格书版本，用户需要改为统一管理规格书模板，再由品线关联使用。规格书独立维护，不再绑定一级品线。一期只在品线管理中关联规格书，候选为全部规格书。

需求依据：用户五项调整及历史兼容说明（2026-11-03）。无真实调研或业务指标基线。示例品线、人员及字段为虚构演示；未连接现有生产系统。

02目标

  • 以规格书名称识别模板，取消面向用户的版本号、版本管理、草稿发布操作。字段标识仅由系统内部维护，不在配置界面展示。
  • 一期不在规格书页面关联品线。二级品线可关联多个规格书，但主模板只能有一个。
  • 新增 SPU 默认使用二级品线主模板，可选范围仅限该二级品线已关联模板。
  • 初始化沿用现有老模板，不在本期改写历史 SPU 数据。

功能验收：初始化后所有二级品线均有有效主模板；跨一级关联与无主模板提交必须被阻止。效果建议：观察配置完成率、错误率及配置耗时，具体基线待试用收集。

04使用场景

  1. 为现有一级品线建立与老模板一致的通用规格书，并设为一级默认。
  2. 建立海外、认证或特殊品类规格书；同一级下多个二级品线关联复用。
  3. 品线管理人员多选关联规格书，为每个二级品线指定一个主模板。
  4. 新增 SPU 自动使用主模板；必要时切换到已关联的其他规格书。
  5. 上线前补齐未配置二级品线的关联和主模板。

06业务流程

初始化与历史兼容

按现有老模板建立一致规格书→设为一级默认模板→未配置二级继承关联→设为二级主模板

用户已确认：新创建 SPU 使用新规则；初始默认仍是一级品线现有老模板。后续二级可关联其他规格书并重新设置主模板。本期不批量改写历史 SPU；历史实例的进一步改造如有需要另行设计。

日常配置

  1. 新增规格书：直接进入配置抽屉填写名称；可选择历史规格书复用字段，再按需修改。不绑定一级品线。
  2. 在抽屉中修改字段，或复用历史规格书字段后再改。保存时校验名称和字段。一期不在规格书页面关联品线。
  3. 品线管理 → 行操作 → 销售属性配置下方「规格书配置」。一级设置默认；二级多选关联并设置一个主模板。
  4. 新增 SPU 选择一级和二级品线，默认带出二级主模板；允许在已关联范围内切换。

一级默认变更不覆盖已有二级主模板；新建二级品线继承当时一级默认模板。任一关联校验失败，整次修改不生效。

07功能说明

创建产品规格书

入口：产品规格书配置 →「新增规格书」。点击后直接打开「新增规格书 · 配置模板」抽屉，不再先弹出名称确认框。规格书名称和字段都在这个抽屉里填写。规格书不绑定一级品线，保存后再到品线管理关联。

字段配置旁可以选择历史规格书并复用其配置字段。复制的是字段快照，包括字段名称、控件类型、是否必填、可选值、默认值和明细表格列。系统重新生成内部字段标识和列标识，不复制品线关联，也不回写历史规格书。已填写的规格书名称保持不变；只有名称为空时，才带出“原名称副本”，避免直接重名。确认后覆盖当前抽屉中的字段，仍可继续增删改。

创建页说明

  1. 顶部填写规格书名称，可随时修改。
  2. 按基础信息、产品结构、产品性能、安规重要零件、产品标贴、产品包装、认证信息七个模块配置字段。模块不必都有字段，但整份规格书至少保留一个字段。
  3. 字段可新增、删除、拖动或用箭头排序。字段标识不展示，保存时由系统自动生成。
  4. 需要沿用已有配置时，选择历史规格书并点击「复用字段」。未选择时提示，不覆盖当前字段；确认后才复制。
  5. 可先预览填写效果，再保存。未改动直接关闭不提示；已修改未保存时关闭会确认。

控件类型配置时怎么填后续填写说明

字段上的「必填」开关默认关闭。打开后，表示后续按该规格书填写时这一项必须填写；它不是创建模板时额外要填的内容。任填组合若同时开启「任填一项即可通过必填」，则多条里填写任意一条即满足必填。

模块入口／展示／操作异常与边界
规格书列表规格书名称、创建人、更新人、修改时间、操作；唯一行操作为「编辑模板」。名称下展示字段数，以及已被多少个二级品线关联。被设为一级默认时有标记。列表不展示版本号，也不按一级品线筛选搜索无结果显示空态并可重置；筛选不修改数据
新增／编辑直接打开抽屉填写名称，不绑定一级品线。七个模块配置字段名称、控件类型、必填、规则、默认值与排序。字段标识不展示，旧值保留，新字段自动生成唯一内部标识名称重复或字段校验失败不保存；新建未保存退出也需确认
字段模块基础信息、产品结构、产品性能、安规重要零件、产品标贴、产品包装、认证信息。后三个模块对已有规格书先显示为空，可直接新增字段模块不必都有字段；整份规格书至少保留一个字段。旧数据打开后不丢失原字段
复用历史规格书字段配置旁选择一份已有规格书，确认后复制字段。编辑时不列出当前规格书自身未选择不覆盖。复制后可修改；保存形成独立副本，不回写来源，不复制品线关联。已填名称保持不变，空名称带出不重复的副本名称
一级配置品线管理 → 一级品线行操作 → 规格书配置。弹窗标题为「一级品线名称-一级品线默认规格书」，不再重复展示品线名称块。提醒为半透明橙色。从全部规格书中单选一级默认模板不能为空。变更不覆盖已有二级主模板；之后新增的二级品线继承该模板，并把它设为唯一主模板
二级配置先点「选择规格书模板」，从全部规格书中勾选；返回后只展示已选规格书，并指定一个主模板未选择规格书不能保存。主模板必须属于已选规格书，且只能有一个。新增二级品线默认继承一级默认规格书
明细表格控件类型新增「明细表格」。配置列名称、控件类型、必填、可选值和顺序；提供「产品主要部件」六列预设。模板只保存列结构，不保存坐垫、底座等示例行预览和新增 SPU 演示按列渲染表格，支持新增行、单行删除、勾选批量删除。必填表格不能以零行或全空行保存；错误定位到具体行和列
上传附件控件类型新增「上传附件」。配置展示固定默认规则：Excel / Word / PDF（.xls、.xlsx、.doc、.docx、.pdf），单文件不超过 90 MB；90 MB = 90×1024×1024 字节，等于上限可选。支持 .xls、.xlsx、.doc、.docx、.pdf。不展示可选值或默认附件输入预览与新增 SPU 演示可选择／移除文件，格式或大小不符立即提示并清除无效选择。仅校验文件名和大小，不读取文件内容、不发起上传、不写入浏览器持久存储；切换模板或关闭预览后选择不保留
上传图片控件类型「上传图片」。配置数量上限 1–20，默认 5。固定规则：jpg、jpeg、png，不区分大小写，单张不超过 20 MB。不设置默认图片超过数量、格式或大小时提示并清除本次选择。只校验文件名和大小，不读取内容、不上传、不写入本地存储
任填组合控件类型「任填组合」。可配置填写提示，并设置「任填一项即可通过必填」。填写界面为一行输入框加加号，与「产品相关认证证书」示例一致开启任填一项时，必填字段填写任意一条即可通过；关闭后已增加的每一条都要填写。模板不保存填写时的示例内容
SPU 演示一级 → 二级 → 规格书；默认二级主模板，展示动态填写表单无有效关联显示错误，不随意回退其他模板；切换重新载入默认值，不提交生产资料
初始化检查展示已配置、待补齐、需人工处理；仅补齐缺失关系缺默认或已有不一致关联阻断整批；再次执行不重复、不覆盖人工主模板

桌面端为主要配置场景。窄屏保留入口和操作，宽字段表横向滚动；不宣称手机端已具备完整生产编辑体验。保存失败显示错误，不标记已保存。

08数据规则

对象核心字段／约束
规格书模板id、name、fields、creator、updater、createdAt、updatedAt。名称去首尾空格，1–60 字符，全部规格书忽略大小写后唯一。不再绑定一级品线，groupId 固定为空
一级品线defaultTemplateId 必须指向一份现存规格书，不限制规格书原来属于哪一级。初始默认由业务对齐现有老模板
二级品线templateIds 从全部规格书中选择，去重且非空；primaryTemplateId 必须唯一且属于 templateIds。新增二级品线继承当时的一级默认规格书
字段至少一个字段；内部标识由系统自动生成、界面不展示，保留旧字段标识，整套模板内忽略大小写唯一。选择类选项不能为空，默认值必须属于选项；数字／日期默认值需有效。上传附件、上传图片都不支持默认文件。图片另存数量上限，必须是 1–20 的整数。任填组合保存填写提示和「任填一项」开关，不保存填写时录入的条目
双向关联一期不在规格书页面维护关联。列表上的关联数量由二级 templateIds 推导，不另存反向关系。品线端保存前整次校验，失败则不部分生效
附件校验附件扩展名忽略大小写匹配 .xls/.xlsx/.doc/.docx/.pdf，大小 ≤ 94371840 字节（90 MB）。图片扩展名忽略大小写匹配 .jpg/.jpeg/.png，单张 ≤ 20971520 字节（20 MB），张数不超过字段配置的数量上限。前端校验只看文件名和大小，不代表文件内容可信。生产上传需服务端复核类型、大小、恶意内容及访问权限
浏览器兼容新键 starmerx-spec-template-studio-v2。旧键 starmerx-spec-field-studio-v1 不删除不覆盖；旧默认字段成为一级模板，旧字段差异保留为独立规格书，由用户确认关联
异常数据无法解析或不支持的结构显示错误并保留原数据，不静默清空重置。跨标签数据变化阻止旧页保存，提示刷新
浏览器旧原型转换仅是演示兼容，不等于生产历史迁移。真实系统需先核对各一级老模板字段完全一致，再进行初始化，不能直接拿虚构示例替代实际模板。

09权限规则

原型现状 无真实登录和服务端权限，操作人为演示用户。静态公开站点使用各自浏览器存储，不共享用户修改，不适合录入业务敏感数据。

正式实施建议 分离规格书维护、品线配置与初始化权限；后端校验规格书存在、主模板唯一、关联非空，以及附件和图片的服务端限制。一期不校验规格书必须属于某一级品线。销售属性原权限保持不变。具体角色、组织隔离及审计要求待业务与研发确认。

12风险与待确认问题

  • 老模板对齐：各一级实际模板及字段来源由业务提供和核对；初始化不以示例数据替代真实数据。
  • 历史 SPU：本期不改写；真实系统模板与历史实例的引用关系需在实施前确认，不假定已有快照机制。
  • 模板编辑影响：配置保存作用于后续新建 SPU 的可用模板；已有实例如何隔离字段变化属于后端落地检查项，不能由静态原型保证。
  • 正式一致性：建议数据库事务与并发控制保证双向变更原子性、主模板约束和初始化幂等；接口结构沿用现有项目标准，尚未指定生产表结构。
  • 初始化上线：先备份与比对老模板 → 创建同一级规格书 → 设置一级默认 → 试运行校验 → 补齐缺失二级关联 → 核对覆盖率 → 开启新建 SPU 规则。阻断清单清零后才启用新规则。
  • 回滚建议：配置开关回退旧 SPU 创建流程，保留新增模板与迁移映射用于核查；不得直接删除已有历史数据。
  • 本地兼容：浏览器数据不是备份；旧键仍保留，未进行自动清理。多用户与多设备数据不互通。
  • 附件上线：真实上传、文件存储、内容安全扫描、下载权限与服务端复核未实现。附件 90 MB、图片 20 MB 与数量上限目前只在前端按文件名和大小校验。原型文件选择不等于文件已上传。
  • 公开边界：仅发布虚构示例与本次允许公开的原型，不包含用户截图、内部网址、实际人员或私有项目。
